Academic Presentation Notes

Project Theme: Abstract Data Type (ADT) Stack Implementation via Cafeteria Tray Model.

1. Core Stack Principles (LIFO)

  • Last-In, First-Out: The element inserted most recently is retrieved first.
  • Encapsulation: Access is restricted strictly to the top pointer.

2. Time & Space Complexity

  • Push / Pop / Peek: O(1) Constant Time.
  • Space Complexity: O(N) linear space relative to the number of elements.

3. Why This Analogy Works

  • Mirrors spring-loaded physical tray dispensers in cafeterias where staff push trays down and customers take from the top.
  • Directly maps to software paradigms like call stack execution frames and undo/redo history buffers.
